# Basu — нууцлал, хамгаалалт, админ системийн архитектур

_2026-09-15. Нэг нийлүүлэгчтэй 9-р сарын нээлт, 2–3 хүнтэй ops багт зориулсан
санал. Хэт том зүйл (тусдаа auth сервер, microservice, Kubernetes) энд байхгүй:
монолит + модулиуд + нэг жижиг `ops` схем нь энэ хэмжээнд яг тохирно._

## 1. Юунаас хамгаалах вэ (threat model)

| Хэн | Юу хийж болох | Одоогийн байдал |
|---|---|---|
| Гадны халдагч | OTP-г олон дугаар руу илгээлгэж SMS-ийн зардал үүсгэх («SMS pumping»), код тааж оролдох, API-г ачаалах, утасны дугаар цуглуулах | Дугаар тутам 3 код/цаг, кодын оролдлого хязгаартай; IP-ээр хязгаар алга, ерөнхий rate limit алга |
| Хорлонтой/хакердуулсан нийлүүлэгч | Зарын гарчигт скрипт хийж зочдын browser-т ажиллуулах (XSS), хуурамч «хүлээлгэн өгсөн», ирээгүй зочны суутгалыг зүй бусаар ашиглах, дансаа сольж олголт чиглүүлэх | Нүүрний вэб хуудсанд escape дутуу; данс солиход хоёр дахь баталгаа алга |
| Хорлонтой зочин | Сесс хулгайлагдвал буцаалтын дансыг солих; QPay банкны төлбөр тул chargeback эрсдэл бага | Данс оруулахад OTP дахин асуудаггүй |
| Дотоод хүн (ops) | Нэг нийтлэг нууц үг: хэн юу хийснийг батлах боломжгүй, нууц үг алдагдвал бүх эрх | `x-ops-name` толгойг өөрөө бичдэг |
| SIM swap (операторын сул тал) | Утас = хэн болох тул нийлүүлэгч, зочин, ops бүгдийг утсаар нь авч болно | Мөнгөтэй үйлдэлд нэмэлт баталгаа алга |
| Дэд бүтэц | Сервер, DB, `.env` нууцууд, backup алдагдах; CDN-ээс ирдэг скрипт солигдох | Нэг VPS, nginx; HSTS/CSP толгой алга; backup хуваарь тодорхойгүй |

## 2. Хэн болох (identity & access)

### 2.1 Зочин
- Утас + OTP хэвээр (хэшлэгдсэн, 5 мин, оролдлого хязгаартай — байгаа).
- Нэмэх: **IP тутмын хязгаар** (10 код/цаг/IP, 60/өдөр), **зөвхөн +976** дугаар, өдрийн нийт OTP-ийн дээд хязгаар ба сэрэмжлүүлэг (CallPro-ийн зардлыг хамгаална).
- **Мэдрэмтгий үйлдэлд OTP-г дахин асуух (step-up)**: буцаалтын данс оруулах/солих, бүртгэл хаах.
- Сессийн жагсаалт, цуцлалт (байгаа), 60 хоног (хэвийн). Бүртгэл устгах товч аппын Профайл хэсэгт — Apple ч шаарддаг (5.1.1(v)).

### 2.2 Нийлүүлэгч
- Эзэн = гэрээний утас (байгаа). Таблет = 8 оронтой код, нэг удаа (байгаа); нэмэх: оролдлогын хязгаар (5/мин/IP), кодыг 10 минутаас илүү хадгалахгүй.
- **Данс солих хамгаалалт**: солихдоо OTP дахин; солигдмогц эзний утсанд SMS; шинэ данс «баталгаажаагүй» төлөвтэй — ops гэрээтэй тулгаж баталгаажуулах хүртэл **олголт хийгдэхгүй**.
- Дараа нь: ажилтны эрх (эзэн: бүх зүйл; ажилтан: захиалгын үйлдэл л, данс/профайл биш).

### 2.3 Ops (админ)
- Нэг нууц үгийг **хувь хүний бүртгэл**-ээр солино: `ops.member` (утас, нэр, эрх, идэвхтэй эсэх). Нэвтрэлт OTP-оор; admin ба finance эрхэд хоёр дахь хүчин зүйл (TOTP эсвэл passkey).
- Эрхүүд: **admin** (гишүүд, тохиргоо, гэрээний нөхцөл), **finance** (олголт/буцаалтыг «шилжүүлсэн» тэмдэглэх, данс харах, экспорт), **ops** (захиалга, нийлүүлэгч батлах, өмнөөс үйлдэх, зар нуух), **viewer** (зөвхөн харах).
- **Дөрвөн нүдний дүрэм**: данс солигдсоны дараах эхний олголт, ба тодорхой дүнгээс дээш олголтыг өөр хүн баталгаажуулна.
- Ops-ийн вэб сесс: httpOnly, Secure, SameSite=Strict cookie, 12 цаг, идэвхгүй бол 1 цагт дуусна; хүсвэл IP-ийн жагсаалт.
- Бүртгэлд (audit) `x-ops-name` биш, **нэвтэрсэн хүний** нэр.

## 3. Аппликейшны хамгаалалт

- **Гаралтын escape бүх газарт** (нүүрний `index.html`-д нийлүүлэгчийн нэр, гарчиг escape-гүй — засна). Хуудасны template-д автоматаар escape хийдэг нэг `h()` тусламж, тест.
- **CSP**: `default-src 'self'; script-src 'self'` (+ SRI-тай CDN), `connect-src` зөвхөн өөрийн API ба газрын зургийн tile, `frame-ancestors 'none'`. Үүний тулд хуудсуудын inline `<script type="module">`-ийг `src/web/js/*.js` файл болгоно.
- **HSTS** (preload), `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy` — nginx дээр.
- **Rate limit**: Fastify-д `@fastify/rate-limit` (нэвтрэлт 10/мин/IP, код холбох 5/мин, ops 100/мин, ерөнхий 300/мин), nginx-д `limit_req` давхар; body 64 KB.
- **Оролтын схем**: зам бүрд JSON schema (Fastify), үл мэдэх талбарыг татгалзана.
- **Токен**: native апп bearer хэвээр (Keychain); вэб хуудас CSP + escape-ээр XSS-гүй болмогц localStorage хүлээн зөвшөөрөгдөнө, дараагийн алхамд cookie сесс.
- **Хамаарал**: `npm audit` CI-д, Dependabot; MapLibre, фонтыг өөрийн серверээс өгч гуравдагч скриптийг арилгана.
- **Мөнгөний инвариант**: ledger-ийн drift = 0 шалгалт өдөр бүр (байгаа функц), олголт зөвхөн баталгаажсан данс руу, settlement ба payable тэнцэх шалгалт.
- **Лог**: request id-тай бүтэцтэй лог; OTP код, токен, дансны дугаар логт хэзээ ч орохгүй; 30 хоног. Нэвтрэлтийн үйл явдлын хүснэгт (`identity.auth_event`: амжилт/алдаа, IP, төхөөрөмж).

## 4. Хувийн мэдээлэл (нууцлал)

- **Тооллого, хадгалах хугацаа**: OTP challenge 24 цагийн дараа устна; кодтой SMS-ийн текст (`notify.message`) 1 хоногийн дараа устна; хугацаа дууссан сесс устна; захиалга, ledger — татварын хуулийн хугацаагаар; хаагдснаас 12 сарын дараа зочны утас хэшлэгдэж, хаяг устна (ledger хэвээр); зочны буцаалтын данс шилжүүлснээс 90 хоногийн дараа устна.
- **Устгах хүсэлт**: `closeAccount` байгаа — аппын Профайлд товч, ops-д «Устгах/нэргүй болгох» хэрэгсэл; нууцлалын бодлогод амласан.
- **Шифрлэлт**: дамжуулалтад TLS + HSTS; серверийн диск шифрлэгдсэн; **дансны дугаарыг талбарын түвшинд шифрлэнэ** (pgcrypto, түлхүүр `.env`-д), UI-д сүүлийн 4 орон л — finance эрхээс бусдад.
- **Хандалт**: DB-д апп хэрэглэгч (DDL-гүй), миграцийн хэрэглэгч тусдаа, зөвхөн-уншдаг хэрэглэгч тайланд; хувийн компьютерээс DB руу шууд орохгүй.
- **Backup**: өдөр бүр `pg_dump` → шифрлэж (age) → серверээс гадуур (S3-төст) → 30 хоног; улирал бүр сэргээж туршина.
- **Хамгийн бага харагдалт**: зочны утас нийлүүлэгчид төлсний дараа л (байгаа); нийлүүлэгчийн утас зочинд төлсний дараа л (байгаа); ops-д данс зөвхөн finance.

## 5. Админ систем (ops desk) — бүтэц

Тусдаа сервер биш, **монолит доторх `ops` модуль**: `src/ops/` (нүүр `index.ts`), схем `ops` (`member`, `session`, `audit`, `setting`, `alert`). `/v1/ops/*` замууд §2.3-ын нэвтрэлтийн ард. `/ops` хуудас нэг л вэб апп хэвээр, хэсгүүд:

1. **Самбар** — өнөөдөр/7 хоног/улирлын тоо (байгаа), сэрэмжлүүлэг: олголт N хоног хүлээгдэж байна, буцаалт данс хүлээж 3 хоног, бэлэн болсон ч ирээгүй, ledger drift ≠ 0, SMS алдаа, OTP-ийн огцом өсөлт, серверийн алдаа.
2. **Захиалгууд** — хоёр vertical хоёулаа (хоол + идэш) нэг цонхонд; шүүлт, түүх, өмнөөс үйлдэх (байгаа, идэш л).
3. **Нийлүүлэгч / ресторан** — бүртгэлийн **шалгах хуудас** (ТТД шалгасан, е-баримт оператор зөвшөөрсөн, данс тулгасан, гэрээ зурсан — огноотой), баримтын зураг, гэрээний нөхцөл, түр зогсоох, зар нуух (байгаа).
4. **Мөнгө** — олголт/буцаалт (байгаа), дөрвөн нүдний баталгаа, банкны файл/CSV экспорт, нийлүүлэгч бүрийн сарын хуулга, нэгтгэл (ledger ↔ QPay ↔ банк).
5. **Зочид** — утсаар хайх, сесс, устгах/нэргүй болгох, буцаалтын данс, мэдэгдлийн түүх.
6. **Мэдэгдэл** — SMS/push лог, хүргэгдээгүй, дахин илгээх, сарын зардал.
7. **Систем** — холболтуудын эрүүл мэнд (QPay, PosAPI, CallPro), ажил (scheduler), **тохиргоо**: шимтгэлийн анхдагч %, суутгал %, ирээгүй зочны хоног, draft-ийн хугацаа — кодоос гаргаж `ops.setting`-д, өөрчлөлт бүр бүртгэлтэй, хүчинтэй огноотой.
8. **Бүртгэл** — ops-ийн үйлдэл (байгаа) + нэвтрэлтийн үйл явдал + тохиргооны өөрчлөлт.
9. **Гишүүд** — admin л: нэмэх, эрх, идэвхгүй болгох.

Ажиглалт: uptime шалгалт, алдааны мөшгөлт (Sentry-төст, өөрөө байршуулж болно), DB метрик.

## 6. Дэд бүтэц

- nginx: TLS 1.2+, HSTS, `limit_req`, body хязгаар, production-д `/dev/*`-ийг nginx дээр ч хаах (давхар хамгаалалт), real-IP → Fastify `trustProxy`.
- Сервер: firewall (22/80/443), SSH зөвхөн түлхүүрээр, fail2ban, аюулгүйн шинэчлэл автомат, апп root биш хэрэглэгчээр (systemd hardening), Postgres зөвхөн localhost, диск шифрлэлт.
- **Орчин**: pilot (демо) ба production **ядаж тусдаа DB, тусдаа `.env`**; бодит мөнгө ормогц тусдаа VPS (хямд) — демо нь үзүүлэх, туршихад үлдэнэ.
- Нууцууд: `.env` root-only 0600, deploy хэрэглэгч ба апп хэрэглэгч тусдаа, түлхүүр солих журам (хэн, хэзээ), GitHub secrets зөвхөн deploy түлхүүр.
- Осол гарахад: ops нууц/сесс алдагдвал → бүх сесс цуцалж солих; SIM swap мэдэгдэл → тухайн нийлүүлэгчийн олголтыг түр зогсоох; мэдээлэл алдагдвал → хэнд, хэзээ мэдэгдэх.

## 7. Дараалал

**0-р үе — нээлтээс өмнө (энэ долоо хоног)**
1. Escape + CSP + толгойнууд + rate limit + SMS pumping хамгаалалт + код холбох оролдлого + OTP цэвэрлэлт.
2. Ops-ийн хувь хүний нэвтрэлт (OTP + зөвшөөрөгдсөн дугаар), эрх, бүртгэлд бодит нэр.
3. Данс солих хамгаалалт: OTP дахин + SMS + «баталгаажаагүй» төлөв.
4. Production-д шилжих шалгах хуудас: горим, шинэ OPS нууц, демо арчих, `/dev/*` гаднаас 404 гэдгийг шалгах, backup гадагш.

**1-р үе — 10-р сар**
5. Админ хэсгүүд: зочид, мэдэгдэл, тохиргоо, сэрэмжлүүлэг; дөрвөн нүдний дүрэм; дансны шифрлэлт; аппд бүртгэл устгах; `npm audit`/Dependabot; лог ба алдааны мөшгөлт.

**2-р үе — 11-р сараас**
6. Тусдаа production орчин; admin/finance-д passkey/TOTP; нийлүүлэгчийн ажилтны эрх; нэгтгэл ба экспорт; гадны нэвтрэлтийн шалгалт (pen test).

## 8. Хийхгүй байх зүйлс

Тусдаа auth сервер (Keycloak), OAuth provider, microservice, Kubernetes, өөрийн шифрлэлтийн алгоритм. Гурван хүн, нэг сервер, нэг монолит — хамгаалалт нь бүтцээс биш, дээрх энгийн, шалгагдсан алхмуудаас ирнэ.
