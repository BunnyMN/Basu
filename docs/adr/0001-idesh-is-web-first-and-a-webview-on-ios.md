# Идэш вэб-ээр бичигдэж, iOS дээр WKWebView-д харагдана

Хоолны vertical нь вэб хуудас (`/dine`) болон түүнийг native-аар дахин бичсэн
SwiftUI дэлгэц гэсэн хоёр клиенттэй. Хоёр дахь vertical болох өвлийн идэшийг
өвлийн идэшний улирал (10–11-р сар) эхлэхээс өмнө буюу зургаан-найман долоо
хоногт гаргах шаардлагатай тул **зөвхөн вэб хуудас** (`/idesh`, `/supplier`)
бичиж, iOS апп түүнийг `WKWebView`-д үзүүлнэ. Native дахин бичилт нь энэ
хугацаанд багтахгүй бөгөөд идэшний дэлгэц (жагсаалт, маягт, төлөв) нь хоолны
аппын газрын зураг, цаг тутмын төлөв шиг native байх шалтгаан багатай.

Хуудас энэ л серверийнх тул зочны token-ыг `WKUserScript`-ээр ачаалахаас өмнө
`localStorage['basu.guest']`-д тарина — вэб клиент token-оо яг тэндээс уншдаг,
хуудас Safari дээр ажилладаг шигээ ажиллана. Аюулгүй байдлын хувьд Safari-д
нээснээс ялгаагүй: хуудас, сервер хоёулаа өөрийнх.

## Хаясан хувилбарууд

- **Native SwiftUI дэлгэц** — хоолны апптай ижил чанар, гэхдээ гурав дахь
  клиент бичих цаг байхгүй. Идэш ажиллаж, хэрэглээ нь native-ыг зөвтгөвөл
  хожим бичнэ; вэб хуудас хэвээр үлдэнэ.
- **Тусдаа сервер** — платформ (`identity`, `ledger`, `notify`) процесс доторх
  функцууд тул тусдаа сервер бол дөрвөн сервер хоорондын API гэсэн үг. Модулийн
  зааг `boundaries.test.ts`-ээр аль хэдийн баригддаг, салгах зам хаагдахгүй.
- **Cookie нэвтрэлт** — серверт хоёр дахь нэвтрэлтийн зам нэмнэ, `/v1` бүхэлдээ
  cookie-г ч шалгах болно.
- **URL-д нэг удаагийн код** — хамгийн зөв, гэхдээ энэ намарт илүүц.

## Үр дагавар

- Идэшний дэлгэцийн шинэчлэл iOS релизгүйгээр гарна.
- iOS дээр WebKit — Apple-ийн өөрийн framework — анх удаа импортлогдоно;
  гуравдагч сан хэвээр байхгүй.
- Аппын «‹ Basu» товч, таб бар нуух, сервергүй үеийн дэлгэц гурав нь webview-ийн
  гадна, аппын өөрийнх хэвээр — хуудас ачаалагдаагүй ч апп хоосон биш.
- Демо цагийн зурвас хоолны хуудсанд байдаг шиг идэшний хуудсанд ч байна: энэ
  нь vertical, shell биш.
