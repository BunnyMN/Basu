# Дизайны эх файлууд

## Аппын икон

`app-icon-source.png` — эх зураг: бөхийн дүр, наалт хэлбэрээр, цэнгэлдэхийн
бүдэгрүүлсэн дэвсгэр дээр.

`ios/Basu/Assets.xcassets/AppIcon.appiconset/AppIcon.png` нь үүнээс гурван
алхмаар гарсан:

1. **Дүрсийг таслах** — macOS-ийн Vision (`scripts/lift-subject.swift`), Preview
   дээр зургаас дүрсийг чирж авдаг яг тэр механизм. Гараар бичсэн аль ч
   threshold-оос цэвэр гардаг.

   ```
   swift scripts/lift-subject.swift design/app-icon-source.png subject.png
   ```

2. **Захыг цэвэрлэх** — Vision наалтын захад цэнгэлдэхийн хэдэн пиксел үлдээдэг.
   Alpha-г 4px элэгдүүлж (`MinFilter(9)`) тэр өнгөт наалдацыг тайрна.

3. **Хүрээлэх** — 1024×1024, `#0F5B3E` ногоон дэвсгэр дээр. Бүсний оосороос
   дээших хэсгийг л авна: 60pt дээр амьд үлддэг зүйл бол **царай**, гутал нь
   тэр хэмжээнд гурван бор пиксел болдог.

Ногоон нь санамсаргүй биш — палитрын `ready` өнгөтэй ойр, наадмын талбайн өнгө,
дүрсийн дулаан арьс болон улаан ханцуйг хамгийн сайн тусгаарладаг. Хөх дээр
хөх өмд нь дэвсгэртээ уусдаг; улбар шар дээр арьс нь бүдгэрдэг.

Харанхуй ба tinted хувилбар одоогоор байхгүй — iOS өөрөө гаргана. Хэрэгтэй
болбол `Contents.json`-д `appearances` нэмнэ.
