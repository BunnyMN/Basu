# Дизайны эх сурвалжууд

## Аппын икон

`app-icon-source.png` — эх зураг: бөхийн дүр, хөх радиаль дэвсгэр дээр,
1254×1254. Аль хэдийн icon болгож зохиогдсон ирсэн.

`ios/Basu/Assets.xcassets/AppIcon.appiconset/AppIcon.png` нь үүнээс хоёр
алхмаар гарсан:

1. **Буланг сэргээх.** Эх зураг өөрийн мурий булантай, гадна нь цагаан.
   iOS икон дээрээ squircle маск өөрөө тавьдаг тул ийм зургийг шууд
   ашиглавал **хоёр дахин мурийж**, булан бүрд цагаан хавирга үлддэг.
   Тиймээс цагаан хэсгийг дэвсгэрээр дүүргэж, мурийлгах ажлыг систем дээр
   нь үлдээнэ.

   Дүүргэлт нь мөрөөр биш, **төвөөс гарсан радиусаар**. Дэвсгэр нь радиаль
   градиент дээр цацрагтай — гадагш нь радиусаар сунгавал өнгө ба цацрагийн
   чиглэл хоёул хадгалагдана; хөндлөн сунгавал цацраг тасарна. Ирмэгийн
   дотор талд байгаа цайвар хүрээг алгасахын тулд 34px дотогшоо түшинэ.

2. **1024×1024 болгож жижигрүүлэх.** Alpha байхгүй байх ёстой — App Store
   тунгалагтай икон авдаггүй, симулятор дээр хар өнгө болж харагддаг.

Скрипт нь нэг удаагийнх тул хадгалаагүй; дээрх хоёр алхам PIL дээр арван мөр.

### Зурган дотроос дүрс тасалж авах

`scripts/lift-subject.swift` — macOS-ийн Vision-ы subject lifting, Preview
дээр зургаас дүрс чирж авдаг яг тэр механизм. Эхний икон гэрэл зургаас
гарсан тул хэрэгтэй байсан; одоогийн эх зураг бэлэн ирсэн тул ашиглаагүй.
Дараа гэрэл зургаас икон хийх бол:

```bash
swift scripts/lift-subject.swift зураг.png subject.png
```

Vision наалтын захад дэвсгэрийн хэдэн пиксел үлдээдэг тул alpha-г 4px
элэгдүүлж (`MinFilter(9)`) тэр өнгөт наалдацыг тайрах хэрэгтэй.

### Хэмжээний тухай

Икон 60pt дээр уншигдах ёстой. Бүтэн биетэй дүр тэр хэмжээнд дулаан толбо
болдог тул эх зураг нь дүрийг фрэйм дүүрэн байрлуулсан байх ёстой — одоогийн
эх зураг үүнийг хийсэн. Харанхуй ба tinted хувилбар байхгүй; iOS өөрөө
гаргана, хэрэгтэй бол `Contents.json`-д `appearances` нэмнэ.
