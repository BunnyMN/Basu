# Дизайны эх сурвалжууд

## Аппын икон

`app-icon-source.jpeg` — эх зураг: бөхийн дүр, наалт хэлбэрээр, бүдэгрүүлсэн
цэнгэлдэхийн дэвсгэр дээр. Icon болгож зохиогдсон ирсэн ч гурван зүйл засах
шаардлагатай байсан.

### 1. Цагаан хүрээ ба давхар мурий

Эх зураг өөрийн мурий булантай, гадуураа цагаан захтай. iOS икон дээрээ
squircle маск **өөрөө** тавьдаг тул ийм зургийг шууд ашиглавал хоёр дахин
мурийж, булан бүрд цагаан хавирга үлддэг.

Тиймээс: агуулга руу нь тайрч, үлдсэн цагаан буланг дэвсгэрээр дүүргэж,
мурийлгах ажлыг систем дээр нь үлдээнэ.

**Дүүргэлтийн чиглэл нь дэвсгэрээс хамаарна.** Энэ зургийнх нь хэвтээ
зурвасууд — тавцан, зам, зүлэг — тул мөр бүрийг өөрийнх нь буланд хөндлөн
сунгана; тэгвэл зурвас үргэлжилнэ. Радиаль градиент дэвсгэртэй зурганд
эсрэгээр нь, төвөөс гарсан радиусаар сунгах нь зөв — эс бөгөөс цацраг тасарна.
Аль ч тохиолдолд ирмэгийн доторх цайвар хүрээг барихгүйн тулд ~16px дотогшоо
түшиж өнгө авна.

### 2. Ойртуулж таслах

Анхны бүтэн фрэйм 60pt дээр бүдэг толбо болсон: дүр жижиг, бүдэгрүүлсэн
цэнгэлдэх нь шуугиан болдог. Хажуу тал бүрээс ~14.5%, дээрээс 10%, доороос 4%
тайрч дүрийг фрэйм дүүрэн болгосон — тэгэхэд царай, улаан ханцуй, хөх өмд
гурвуулаа springboard дээр уншигдана.

Икон бүрийг **60pt дээр шалга.** Тэр хэмжээнд амьд үлдэхгүй бол дэлгэц дээр
байхгүйтэй адил.

### 3. Alpha арилгах

1024×1024, alpha-гүй. App Store тунгалагтай икон авдаггүй, симулятор дээр хар
болж харагддаг.

### Гэрэл зургаас дүрс тасалж авах

`scripts/lift-subject.swift` — macOS-ийн Vision-ы subject lifting, Preview дээр
зургаас дүрс чирж авдаг яг тэр механизм. Энэ эх зураг бэлэн ирсэн тул
ашиглаагүй; гэрэл зургаас шинэ икон хийх бол:

```bash
swift scripts/lift-subject.swift зураг.png subject.png
```

Vision наалтын захад дэвсгэрийн хэдэн пиксел үлдээдэг тул alpha-г 4px
элэгдүүлж (`MinFilter(9)`) тэр өнгөт наалдацыг тайрна.
