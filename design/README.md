# Дизайны эх сурвалжууд

## Аппын икон

`app-icon-source.png` — эх зураг: бөхийн дүр, наалт хэлбэрээр, бүдэгрүүлсэн
цэнгэлдэхийн дэвсгэр дээр, 1019×1543 босоо.

```bash
python3 scripts/make-app-icon.py design/app-icon-source.png \
    ios/Basu/Assets.xcassets/AppIcon.appiconset/AppIcon.png \
    --figure 128,242,900,1428
```

Скрипт өөрөө яагаад ийм байгааг тайлбарласан. Хамгийн чухал нь:

**Босоо эх зургийг өг, дөрвөлжинг нь биш.** Толгойн дээрх зай зохиогддоггүй.
Дөрвөлжин болгож аль хэдийн тайрсан зурагт тэнгэр байхгүй тул томруулах бүрд
толгойн орой тасарна; мөр давтаж «тэнгэр» хийхийг оролдвол оёдол харагдана.
Босоо эх зурагт цэнгэлдэх нь дээрээ, зүлэг нь доороо байгаа — хэрэгтэй зүйл
бүр зурган дотроо байна. Зөвхөн хажуу талыг сунгана, тэнд бүдэг тавцан байгаа
тул мэдэгдэхгүй.

**Дүрсийн байрлалыг Vision-оор хэмжинэ, нүдээр биш.** Цэнгэлдэхийн бүдэг олон
түмэн цагаан цамцтай тул «цагаан контур» гэсэн энгийн шалгуур ажиллахгүй.
`--figure` аргументыг `scripts/lift-subject.swift`-ийн гаргасан хэмжээнээс ав.

**60pt дээр шалга.** Икон 1024 дээр хэн ч харахгүй. Симулятор дээр суулгаад
springboard-ын зургийг ав — бусад иконы дунд яаж харагдахыг л шалгах хэрэгтэй.

Одоогийн тохиргоо: дүрс тайлын 87%, толгойн дээр 8%, гутлын доор 5%, хажуу
тал бүрийн 13% нь сунгасан дэвсгэр.

Харанхуй ба tinted хувилбар байхгүй; iOS өөрөө гаргана. Хэрэгтэй бол
`Contents.json`-д `appearances` нэмнэ.

`handoff/` — 14 artboard (launcher 1/4/9 икон, түрийвч, мэдэгдэл, профайл,
гэрэл ба харанхуй), токен, icon системийн дүрэм, аватарын алгоритм.
`Basu Shell.dc.html`-ийг браузераар нээнэ. Хэрэгжүүлэлт нь `ios/Basu/Design/`,
`Home/`, `Platform/` гурван хавтаст.
